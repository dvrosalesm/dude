#04 save-this-or-regret

stop writing
try/catch
around everything.

if you catch everything, you handle nothing. let the app crash — logs will thank you. sentry will thank you. your future self will buy you a beer.

◆ don't // you, yesterday try { ship() } catch (e) { /* nothing */ } → error? dunno.
◆ do // you, tomorrow try { ship() } catch (e) { logger.fatal(e); throw e } → loud & logged
