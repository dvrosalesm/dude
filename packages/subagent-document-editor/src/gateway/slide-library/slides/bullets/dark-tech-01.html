Fork & stream --stream sse

Every agent process streams tokens over plain SSE. Back-pressure handled by the runtime; your client just keeps reading until [DONE].

p95: 42ms first token · retry: exponential
⎔

Isolated DB per workspace wk_*.db

Each agent gets its own SQLite, downloaded from R2, decrypted at boot, sync'd back on idle reap. Zero shared state.

encrypt: AES-256-GCM · sync: on-stop
☣

Sandboxed tools runner.py

Restricted __builtins__, import whitelist, SQL ATTACH/readfile/writefile blocked. No exec, no open, no footguns.

cve: 0 open · scan: nightly
⟳

Idle reaping TTL=5m

Orphan agents auto-stop, flush state, release the port. Next request warm-starts from the snapshot in R2 in ~280ms.

billed: active-seconds · cost: $0.00012/s
