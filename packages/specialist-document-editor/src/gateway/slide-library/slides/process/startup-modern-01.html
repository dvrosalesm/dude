Request lifecycle
01 Request lands

02 DB provisioned

If this workspace has a saved archive in R2, we download, decrypt, and write it to a fresh temp directory with a UUID path.

→ decrypt → /tmp/...
→
03 Process spawned

We fork a tsx child process on a free port with a minimal env — no Supabase keys, no R2 keys, just the workspace config.

spawn("tsx server.ts")
→ port 42701
→
04 Streaming ready

The child process reports back over an internal socket. We return the agent ID; your chat client starts streaming over SSE.

GET /chat
→ text/event-stream
