★ Our Operating Agreement · v2

Six things we promised
each other we'd do.

✓

Ship every Friday, even small.

Streak: 142 weeks. Streak we're proudest of: last Friday's two-line fix that closed a 3-year-old ticket.

weekly!
✓

Write docs before code.

If we can't describe the feature in five sentences, it isn't ready. If it's only three sentences, it probably doesn't need to exist.

✓

No meetings before noon on Wednesdays.

Sacred. Enforced by a small cactus named Ferdinand.

sacred!
✓

One on-call per quarter, max.

If one person is on-call twice, we've failed and we fix the system, not the rotation.

✓

Customers first, then quiet.

We reply to every support email in under four hours, and we don't pipe it through a bot first. Quality beats response time, but we can do both.

xoxo
✓

Have fun. It matters.

If the work isn't fun this quarter, we talk about it. Most of our best features came from a Friday afternoon of messing around.
